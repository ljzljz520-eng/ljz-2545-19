验收场景（自动测试）

服务端内置零依赖验收脚本 npm test，覆盖以下场景：

  • 改线后补交旧回访 → 绑定旧几何版本，不刷新新线复查日期
  • 两人观察冲突 → 同点 72h 内结论不一致被标红待核
  • 附件缺失 → 事件标记 attachmentsComplete=false 并列出缺项
  • 超期 → 整线模型与分段模型分别给出 expired 时点
  • 网络重试 → clientEventId 幂等，重复附件去重
  • GPS 漂移/漏段 → 显示未核原因，未走部分不记为已核
  • 晚上传 → observedAt 与 receivedAt 分离，lateUpload=true
  • 照片 EXIF GPS → 公开件剥离、原件管理员受控访问
  • 依赖推荐缓存 → 改线/事件变化使标签版本前进，旧缓存失效

页面信息时效说明

“最近可确认的覆盖时点”表示系统有据可查的最近观察时刻， 仅说明信息的新近度；路况随时可能变化（施工、事故、天气）， 该信息不构成对当前路况或通行安全的保证。出行请以现场状况与官方通告为准。
